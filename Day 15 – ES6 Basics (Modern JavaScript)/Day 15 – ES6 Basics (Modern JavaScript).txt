🟢 1️⃣ Arrow Functions

Old way:

function add(a, b) {
    return a + b;
}

New way:

const add = (a, b) => {
    return a + b;
};

Short version:

const add = (a, b) => a + b;
🟡 2️⃣ Template Literals (Very Important 🔥)

Old:

let name = "Vinesh";
console.log("Hello " + name);

New:

let name = "Vinesh";
console.log(`Hello ${name} 🔥`);

👉 Backticks ` use pannanum.

🟠 3️⃣ Destructuring (Power Concept)

Array:

let numbers = [10, 20];

let [a, b] = numbers;
console.log(a);

Object:

let student = {
    name: "Vinesh",
    age: 21
};

let { name, age } = student;
console.log(name);
🔵 4️⃣ Spread Operator (...)
let arr1 = [1,2,3];
let arr2 = [...arr1, 4,5];

console.log(arr2);
🟣 5️⃣ Rest Operator
const sum = (...nums) => {
    return nums.reduce((total, num) => total + num, 0);
};

console.log(sum(1,2,3,4));
