📅 Day 2 – Data Types + Operators

⏰ Time: 2–3 Hours
🎯 Goal: Numbers, Strings, Boolean full clarity

🟢 Step 1 – Data Types

1️⃣ Number
let age = 21;
console.log(typeof age);

2️⃣ String
let name = "Vinesh";
console.log(typeof name);

3️⃣ Boolean
let isStudent = true;
console.log(typeof isStudent);

4️⃣ Undefined
let x;
console.log(x);

5️⃣ Null
let data = null;
console.log(data);

⚠ Interview Trap:
console.log(typeof null); // object 😮

🟡 Step 2 – Operators
➕ Arithmetic
let a = 10;
let b = 5;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);

➕ Assignment
let x = 5;
x += 3;  // x = x + 3
console.log(x);

➕ Comparison
console.log(10 > 5);
console.log(10 == "10");   // true
console.log(10 === "10");  // false (IMPORTANT)

👉 == checks value
👉 === checks value + datatype (Use this always)

➕ Logical
console.log(true && false);
console.log(true || false);
console.log(!true);
