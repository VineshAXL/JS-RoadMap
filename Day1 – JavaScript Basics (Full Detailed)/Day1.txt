Step 2 – Variables

Variables na data store panna use pannuvom.

1️⃣ let

Value change panna mudiyum.

let age = 21;
age = 22;
console.log(age);

2️⃣ const

Value change panna mudiyathu.

const pi = 3.14;
console.log(pi);

3️⃣ var (Old method)

Ipove use panna koodathu (but concept theriyanum)

var name = "Vinesh";
console.log(name);

🟠 Difference (Important Interview Question)
let	            const         	var
Can change	    Cannot change	Old
Block scope	    Block scope	    Function scope
