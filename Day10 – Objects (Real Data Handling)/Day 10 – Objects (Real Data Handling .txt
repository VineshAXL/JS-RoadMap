⏰ 2–3 Hours
🎯 Goal: Real data structure puriyanum

🟢 1️⃣ What is Object?

👉 Real world entity represent panna use pannuvom.

let student = {
    name: "Vinesh",
    age: 21,
    city: "Chennai"
};
console.log(student);

🟡 2️⃣ Access Properties

Dot notation
console.log(student.name);

Bracket notation
console.log(student["age"]);

🟠 3️⃣ Update Property

student.age = 22;
console.log(student);

🔵 4️⃣ Add New Property
student.course = "Full Stack";

🟣 5️⃣ Object inside Array (Very Important 🔥)
let students = [
    {name: "Vinesh", marks: 80},
    {name: "Arun", marks: 45},
    {name: "Kumar", marks: 90}
];

console.log(students[0].name);

🟤 6️⃣ Loop Through Object Array
students.forEach(student => {
    console.log(student.name + " - " + student.marks);
});
