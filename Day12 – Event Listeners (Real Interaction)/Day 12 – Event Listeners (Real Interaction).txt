🟢 1️⃣ What is Event?

submit

🟡 2️⃣ addEventListener() (Correct Method 🔥)

HTML:

<h1 id="title">Hello</h1>
<button id="btn">Click Me</button>

JS:

let button = document.getElementById("btn");

button.addEventListener("click", function() {
    document.getElementById("title").innerText = "Button Clicked 🔥";
});

👉 Best practice → onclick use panna koodathu.
👉 addEventListener use pannanum.

🟠 3️⃣ Counter Example

HTML:

<h2 id="count">0</h2>
<button id="increase">Increase</button>

JS:

let count = 0;
let btn = document.getElementById("increase");

btn.addEventListener("click", function() {
    count++;
    document.getElementById("count").innerText = count;
});
🔵 4️⃣ Change Background Color
document.body.addEventListener("click", function() {
    document.body.style.backgroundColor = "lightblue";
});
🟣 5️⃣ Input Field Example

HTML:

<input type="text" id="nameInput">
<button id="show">Show</button>
<p id="output"></p>

JS:

document.getElementById("show").addEventListener("click", function() {
    let value = document.getElementById("nameInput").value;
    document.getElementById("output").innerText = value;
});
