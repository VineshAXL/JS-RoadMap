🟢 1️⃣ What is Callback?

👉 One function inside another function pass pannuvom.

function greet(name, callback) {
    console.log("Hello " + name);
    callback();
}

function sayBye() {
    console.log("Goodbye 👋");
}

greet("Vinesh", sayBye);

👉 sayBye is callback function.

🟡 2️⃣ setTimeout() – Delay Execution
setTimeout(function() {
    console.log("Hello after 3 seconds ⏳");
}, 3000);

👉 3000 = 3 seconds (milliseconds)

🟠 3️⃣ Arrow Function Version
setTimeout(() => {
    console.log("Delayed Message 🔥");
}, 2000);
🔵 4️⃣ setInterval() – Repeat Execution
setInterval(() => {
    console.log("Repeating every 2 seconds 🔁");
}, 2000);
🟣 5️⃣ Stop setInterval
let interval = setInterval(() => {
    console.log("Running...");
}, 1000);

setTimeout(() => {
    clearInterval(interval);
}, 5000);

👉 After 5 seconds stop aagum.
