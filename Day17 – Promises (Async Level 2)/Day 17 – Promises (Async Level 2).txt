🟢 1️⃣ What is Promise?

Promise = Future la complete aagum operation.

3 States irukum:

🟡 Pending

🟢 Resolved

🔴 Rejected

🟡 2️⃣ Basic Promise Syntax
let myPromise = new Promise((resolve, reject) => {

    let success = true;

    if (success) {
        resolve("Operation Successful ✅");
    } else {
        reject("Operation Failed ❌");
    }

});

myPromise
    .then(result => console.log(result))
    .catch(error => console.log(error));

👉 resolve → success
👉 reject → error
👉 then() → handle success
👉 catch() → handle error

🟠 3️⃣ Promise with setTimeout Example
let loginPromise = new Promise((resolve, reject) => {

    setTimeout(() => {
        let loginSuccess = true;

        if (loginSuccess) {
            resolve("Login Success 🔥");
        } else {
            reject("Invalid Credentials ❌");
        }

    }, 2000);

});

loginPromise
    .then(msg => console.log(msg))
    .catch(err => console.log(err));

👉 2 seconds delay → result varum.

🔵 4️⃣ Chaining Promises (Very Important 🔥)
new Promise((resolve) => {
    resolve(10);
})
.then(num => {
    console.log(num);
    return num * 2;
})
.then(result => {
    console.log(result);
});

👉 Output:
10
20
