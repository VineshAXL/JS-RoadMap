Day 5 – Loops (Programming Power 🔁🔥)

⏰ Time: 2–3 Hours
🎯 Goal: Repetition logic strong aaganum

🟢 1️⃣ for Loop (Most Important)
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
👉 Output: 1 2 3 4 5

Structure:

for (initialization; condition; increment)

🟡 2️⃣ Print 1 to 100

for (let i = 1; i <= 100; i++) {
    console.log(i);
}

🟠 3️⃣ Even Numbers 1–50

for (let i = 1; i <= 50; i++) {
    if (i % 2 === 0) {
        console.log(i);
    }
}

🔵 4️⃣ while Loop
let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

🟣 5️⃣ Multiplication Table
let num = 5;

for (let i = 1; i <= 10; i++) {
    console.log(num + " x " + i + " = " + (num * i));
}
